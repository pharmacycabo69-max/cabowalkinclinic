# Drafts (not published)

Pages moved here are the equivalent of WordPress "draft" status: the files are kept
(nothing deleted) but renamed `index.html.draft` so they are not served as web pages.

Contains the pharmacy / prescription / medicine-delivery pages (the pharmacy service is
advertised from another domain), plus the WordPress feed and comments mirrors.

To republish a page: move the folder back to the site root and rename
`index.html.draft` to `index.html`.
